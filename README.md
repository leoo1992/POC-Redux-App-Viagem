# POC Redux — App de Viagem

Prova de conceito de uma interface de planejamento de viagens, usando React e Redux para compartilhar o estado entre componentes.

## Stack
- React 18
- Redux
- JavaScript
- Create React App

## Como executar

```bash
npm install
npm start
```

Acesse http://localhost:3000. Testes: `npm test`; build: `npm run build`.
